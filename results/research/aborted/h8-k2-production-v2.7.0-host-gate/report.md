# K2 相对生产 K1 的正式晋级实验

- 配对服务样本：30 组；每个 arm 均进入真实 Paged 图且零 fallback。
- 客户端配对中位差（K2-K1）：-1.028 ms；bootstrap 95% 区间 [-5.095, 1.618] ms。
- 客户端 P95：K1 57.253 ms，K2 55.897 ms，变化 -2.37%。
- 服务内部 prompt 配对中位差：-0.040 ms。
- NSYS：K1 24 次 / 0.438 ms；K2 24 次 / 0.228 ms（仅机制证据）。
- 生产晋级：通过。门槛为客户端 median/P95 回退均不超过 5.0%，且 kernel 总时长至少降低 20.0%。

该结论只回答 K2 能否替代同一 Paged 路径中的 K1；不把它改写成 Paged 已优于 Direct。
