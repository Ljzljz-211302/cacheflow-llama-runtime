# K2 相对生产 K1 的正式晋级实验

- 配对服务样本：30 组；每个 arm 均进入真实 Paged 图且零 fallback。
- 客户端配对中位差（K2-K1）：0.431 ms；bootstrap 95% 区间 [-0.534, 0.928] ms。
- 客户端 P95：K1 31.747 ms，K2 34.691 ms，变化 9.27%。
- 服务内部 prompt 配对中位差：0.554 ms。
- NSYS：K1 24 次 / 0.404 ms；K2 24 次 / 0.199 ms（仅机制证据）。
- 生产晋级：未通过。门槛为 P95 回退不超过 5.0% 且配对中位数不慢。

该结论只回答 K2 能否替代同一 Paged 路径中的 K1；不把它改写成 Paged 已优于 Direct。
