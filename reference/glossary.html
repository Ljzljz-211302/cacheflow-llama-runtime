CacheFlow Runtime 术语表

面试中术语必须稳定。以下定义以本项目语义为准；同名概念在别的框架中可能具有不同实现。

术语准确含义项目中的落点
Prefill一次并行处理 prompt tokens，构造每层 KV 并产生首个输出位置所需状态；通常计算密集，直接影响 TTFT。Scheduler 的 prefill token/chunk 预算。
Decode自回归逐 token 生成；每个 sequence 每轮通常只增加一个 token，容易受内存带宽和 batch 宽度影响。iteration-level batch 中的 decode token。
TTFTTime To First Token，从请求进入服务到首个非空流式 token 的时间。`llama_lab.streaming` 与 benchmark。
TPOTTime Per Output Token，首 token 后生成每个输出 token 的平均/分位间隔；不要和总 latency 混淆。server benchmark 汇总。
Iteration-level scheduling每次只为下一次模型迭代选 batch，迭代结束后允许新请求加入、旧请求完成或被抢占。`server-inference-engine.*` / `server-inference-scheduler.*`。
Chunked Prefill把长 prompt 的 prefill 切成多轮，减少单轮对 decode 的阻塞；代价是更多轮次和调度/launch 开销。Adaptive Prefill 候选动作。
KV Cache每层历史 token 的 Key/Value 张量，避免 decode 时重复计算历史 K/V；不是保存 attention 输出。`llama-kv-cache*` 与 block runtime。
Logical blocksequence 看到的有序 token 块编号。Block Table 左侧索引。
Physical blockKV 存储中真正占容量、带 refcount 的块。`server_kv_block_manager`。
Prefix sharing多个 sequence 的逻辑块映射到相同物理块，复用公共 prompt 的 KV。PrefixIndex + refcount。
COWCopy-on-Write：共享块在写入前复制，随后写者改映射，其他引用保持旧数据。partial-tail append 路径。
Preemption资源不足时暂时移出某 sequence 的可执行状态；可重算或 swap，而非等同于取消。PreemptionPolicy / KvSwapStore。
Swap把 KV 从运行存储迁到 Host/File/CUDA backing store，并在恢复时重建映射；必须有事务语义。`server-kv-swap-store.*`。
Shadow plan不立即提交副作用的候选计划，用于比较 upstream 与 CacheFlow 的预测成本。Benefit Gating 决策 seam。
Ridge regression带 L2 正则的线性回归，缓解少样本/共线特征导致的不可逆或高方差。`server_benefit_policy::ridge_model`。
Confidence radius当前上下文在参数不确定性下的预测误差尺度；数据覆盖差时更大。收益下界判定。
Safe exploration在结构安全区间内、有频率和总预算限制的试探动作；不等于模型已确信动作更优。`safe_exploration` reason。
Positive lower bound即使把 CacheFlow 成本上调、upstream 成本下调并加 margin，CacheFlow 仍预测更优。真正的 learned exploitation。
Distribution shift线上特征/反馈分布变化，使旧模型关系失效；不能把单次 SLO miss 自动等同于 drift。residual streak + cooldown。
CUDA stream同一 stream 内按序执行的一列 GPU 命令；不同 stream 可能并发，但正确性不能依赖“碰巧并发”。KV gather/scatter/swap 异步路径。
CUDA event插入 stream 的时间戳/依赖对象，能测设备执行区间，也能建立跨 stream happens-before。KV kernel/copy Event 计时。
Kernel launchHost 向 GPU 提交一个 grid；launch 通常异步，过碎的 kernel 会引入调度和同步成本。paged KV gather/scatter/COW。
Counter单调递增、重启可归零的累计量。decisions、fallback、drift 次数。
Gauge可增可减的当前值。terminal predicted benefit/uncertainty。
Causal chain受控干预 → 中介变化 → 系统结果变化；比单张 profiler 截图更能支持因果解释。paired Latin upstream/always 实验。

主要参照：Orca、PagedAttention、CUDA Programming Guide、Prometheus。
