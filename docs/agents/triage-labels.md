# Triage Labels

工程技能使用以下五种标准分流角色，并直接映射到同名 GitHub 标签。

| Canonical role | GitHub label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由代理独立执行 |
| `ready-for-human` | `ready-for-human` | 需要人工执行或决策 |
| `wontfix` | `wontfix` | 不计划执行 |

技能提到角色时，使用本表右侧对应的实际标签；若以后更改 GitHub 标签，只修改本表映射。
