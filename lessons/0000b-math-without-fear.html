看懂项目公式所需的最少数学

不追求一节课学完线性代数，只建立后续公式每个符号的含义和直觉。

1. 标量、向量、矩阵

标量是一个数，例如耗时 12ms。向量是一列有顺序的数，例如用 x=[并发数, prompt长度, KV压力] 描述一次系统状态。矩阵是按行列排列的数表，可以表示一组数据或一种线性变换。

x=[2, 512, 0.7]　　θ=[3, 0.01, 8]
xᵀθ = 2×3 + 512×0.01 + 0.7×8 = 16.72

点积xᵀθ把对应位置相乘再相加。在线成本模型用它把多个特征合成一个预测耗时。

2. 矩阵乘法在做什么

矩阵乘向量，可以理解为“同时计算多个加权和”。神经网络的线性层正是大量这类计算。GPU 擅长它，因为许多乘加可以并行。

转置Xᵀ是把行列交换；单位矩阵I像数字 1；逆矩阵A⁻¹类似除法，但只有满足条件的方阵存在。后续 Ridge 加上 λI，就是为了让求解更稳定。

3. 平均数、中位数和 P95

  • 平均数：总和除以数量，容易受极端值影响；
  • 中位数：排序后居中的数，描述“典型一次”；
  • P95：排序后 95% 样本不超过的值，关注较慢尾部；
  • 方差：样本相对平均值波动有多大。

例：耗时 [10,10,11,12,100]，中位数 11，平均数 28.6。只报平均数会被一次 100 强烈拉高；只报中位数又会隐藏严重尾延迟，所以 serving 常同时报告中位和 P95。

4. 概率与 softmax

概率在 0 到 1 之间，总和为 1。模型先输出任意实数分数（logits），softmax把它们转换成概率：

softmax(zᵢ)=ezᵢ/Σezⱼ

分数差越大，概率越集中。后续 Attention 也使用 softmax，把 query 与各历史 key 的相似分数变成权重。

5. 回归与误差

回归是根据输入特征预测连续数值，例如预测一次迭代耗时。预测值与真实值之差叫残差。普通线性回归选择参数，使残差平方和尽量小。

预测 ŷ=xᵀθ　　残差 e=y−ŷ　　损失 Σe²

平方让正负误差不会抵消，也更重罚大误差。Ridge 再加 λ||θ||²，限制参数过大，降低少量数据下的剧烈摆动。

6. “置信”不是“保证”

估计来自有限数据，因此预测有不确定性。项目用“预测值 ± 半径”表示当前证据范围。数据越少或当前状态越陌生，半径通常越大。它是模型假设下的风险尺度，不是绝对不会超出的法律保证。

手算：对数据 [8,9,10,11,32] 算平均数和中位数；指出哪个更代表典型请求、哪个提示系统总成本。再用 x=[2,4]、θ=[3,5] 算点积。
